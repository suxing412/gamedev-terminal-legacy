# 游戏开发者终端 · 坐席

一块全屏常驻的值班屏。它替代的是那个总监 CLI 窗口——不再是「手动点过或不过」，
而是能坐下来问、能追问、能顺着上一句往下说。

**2026-09-02 改成单栏。** 原来是左「等你拍板」/ 中「对话」/ 右「产线脉搏」三栏常驻，
制作人的原话是「我不想进到其它标签页的时候左右两边还有这两列，很奇怪」。
现在：**顶条那 44px 三格答三问**（活着 / 在跑什么 / 谁等我），
「等你拍板」与「产线脉搏」各自成页，主区一次只装一件事。

## 两个仓

形制照监制台那一对：**公开仓是产品本身、迭代发生在那里；私有仓是拿来用的那一份。**

| | 仓 | 干什么 |
|---|---|---|
| 公开 | [`gamedev-terminal`](https://github.com/suxing412/gamedev-terminal) | 产品本身。**迭代都在这里** |
| 私有 | `gamedev-terminal-private` | 镜像，跑起来用的那一份 |

```bash
npm run 镜像
```

一条命令把公开仓的当前状态镜像到私有仓，并**用三个哈希相等来判成功**——
不是「push 没报错」。这与换装仪式第 7 条同一个道理：命令跑通不等于那件事发生了。

> 做成命令而不是做成规矩：「记得推一下私有仓」这种事漏掉的时候不会报错，
> 两边就这么慢慢分了家，而分家的表现是「我在公开仓修好的那个 bug，用的那份还在犯」。

## 怎么打开

双击 `D:\GitHub\gamedev-terminal\启动.bat`。

它会起服务（已在跑就跳过），然后用 Chrome 的 `--app` 模式开一个没有地址栏和标签页的全屏窗口。
想手动开：先 `node server.js`，再浏览器访问 `http://127.0.0.1:4280`。

前提：**监制台要在跑**（`http://127.0.0.1:4270`）。它不在，顶条与那两页会明说「读不到」，对话照常可用。

## 顶条那三格

拆栏之后这条 44px 是屏上**唯一一处一直在视野里**的东西，三问全压在它身上。
一格进不进来的判据两条：**数据源不可达时也说得出真话**、**不需要第二个数配合就能读**。

| 格 | 宽 | 说什么 |
|---|---|---|
| 脉点 | 6px | 绿＝监制台与派单器都通；红＝任一断；灰＝这一格自己没取到数 |
| 人闸 | 232px | `24验收 · 1定夺 · 11解除停靠` ＋ 年龄章 `14天`。按动作键分批——同一批是**一次**处置，不是 24 次 |
| 产线 | 184px | 六态判别。第五态 `零在跑 · 全卡在你`＝没在跑、没待跑，而闸上还压着东西 |

原来还有徽标、脉文、额度、登录、钟五格，2026-09-02 一并砍掉：
徽标是写死的假断言（JS 从没写过它，而它常年宣称「总监在岗」）；
额度那块表**量的不是把闸的那个量**（真 hit limit 那一分钟 5h 窗读数是 7%）；
登录与钟促成不了任何动作。要紧的两件事改成**过线才长出来的横幅**（额度 ≥85% / 数据陈旧），
平时零像素。

## 各页在干什么

**「等你拍板」页**——分两组，都是等你一次判断，只是性质不同。

*单据*：从监制台 `/api/attn` 拉人闸债，只留归属是「制作人」或「双」的，按停摆时长降序。
等得越久颜色越重：超 24 小时染琥珀底，超 72 小时连单号一起转深。

*机制*：政策与机制类决定，读自 `待办-制作人议程.md`（跳过已定的 ✅ 与标 🔧 的「我来干」）。
这一路是 08-27 00:30 补的，起因是那天夜里堵住整夜排程的决定——「注册监制台为项目」——
`/api/attn` 里查无此项：闸注册表只登记**单据级**闸，机制类决定不进任何队列，只落 journal 散文。
议程第 36 条列了两条出路（①机制项也登记成闸债 ②屏幕读议程档），**候你裁**；在那之前这一路是桥。

按闸位分组，组头右边有「**一次处置 24 单**」——同一闸位的单动作键完全相同，
把它们摊成 24 条是把一次批量处置误报成 24 个待决定。那个钮在原来 340px 的栏里排不下，
**这就是拆栏真正换来的东西**。点组里任一条或那个批量钮，内容会落进说框。

议程那 25 条单独一段，不跟单据混排：它读自 `待办-制作人议程.md`，没有活时钟
（文件里写死的小时数已经是错的），不能跟有停摆时刻的单据一起参加年龄排序。

**对话页**——跟总监说话。走的是本机 `claude` CLI（订阅额度，不是 API key），
会话 id 存在 `.session.json`，所以**跨消息记得上文**：你可以说"刚才那些单里，TK-207 呢"。
逐字流式返回；它去翻工单的那两分钟里，转圈处会显示它此刻在读哪份东西，不是干等一个不动的「思考中」。
`Enter` 发送，`Shift+Enter` 换行，`/` 聚焦输入框，`Esc` 清空。

对话页右边有**在座栏**：每席一行，头像 + 名 + **这一席管什么**。那句话来自 `/api/seats`
（每一席协议里的原话），不是编的；点名字开 1:1 私聊。
它**只在对话页出现**，切页签就收起——不然就是把刚拆掉的毛病换个名字请回来。

某一席正在答话时，第二行换成**它此刻在做什么**（「正在读 TK-207 的回执」）。
那句话是坐席自己报的 `tool_use`，与屏上转圈处显示的是同一句——一个值发两处，
不给「两句都自称是它在做什么」留口子。它还没动手时只说「正在答话…」，**不编一个具体动作**。

**「席位」页**——一席一份协议文档，见下。

## 席位：一席＝一份协议

制作人 2026-09-02 拍板：「智能体协议就按照文档库里的，可以直接在自定义中跳转到
文档库中开编辑器进行编辑」。

所以这一页**故意没有表单**。改名、改人设、改人格、改边界，一律去文稿台改那份 `.md`。
协议档是这一席的唯一事实源——一个字段两个改法（页面上一个输入框、文档里一份正文）
就是两本账，而两本账迟早会有一天只改了其中一本，且没有任何东西会报错。

- 自定义席位落在 `席位/<名>.md`，frontmatter 写 `名 / 接模型 / 模型 / 一句话`，正文就是协议
- `席位/_共守.md` 是**九席同一份**的底线（同事不是助手、会说「这条我判错了」、不谄媚不惊叫），
  取自 `PRODUCT.md` 的 Brand Personality。它单独一份，不抄进每一席——抄九份就一定有一天只改了三份
- 每一席自己那份只写**与别人不同的地方**：职责 / 人格特征 / 语言风格 / 招牌动作 / 失手时 / 边界
- 骨架里还有一段「试音」：同一件事这一席会怎么说。**人格只有能当场核对才不是四个形容词**——
  读着不像这一席，说明协议还没写准，不是模型不听话
- 「＋ 新建席位」只建一张填空骨架并把你送去文稿台改它，**不替你写人设**

内建那七席的人设暂时还写在 `server/lib/坐席.js` 里，没搬进文档（席位页上标着「内建」）。

**凭据横幅**——登录**临期或过期时**顶条下面会挤出一行琥珀横幅，直接给出重登命令和一个复制钮；
登录有效时这一行完全不存在（不占一个像素）。

这一路是 08-27 02:19 补的：那晚 token 到期前 18 分钟才有告警，而过期后坐席开口只会吐一团 401 的
鬼话。现在坐席遇到认证失败会说人话——「登录已过期 N 分钟，重登一下就恢复」外加那条命令。
服务端只读 `~/.claude/.credentials.json` 里 `claudeAiOauth.expiresAt` **这一个数字**，
不读、不回、不记 token 本身（这块屏是常驻全屏的，任何时候都可能有人从旁边走过）。

**「监视」页**——原来那条右栏（各态计数 + 正在跑的会话）2026-09-02 并到了这一页。
并过来的正当性不只是腾地方：**它与这一页本来就在渲染同一批事件**，
同一个 `事流.事条()` 在两处各画一份、各自定时刷新，合并之后只剩一处。
关键词（失败/急件/滞留/裁决/落袋/废弃）会加重。

## 边界（故意这么定的）

- **写权在监制台**。终端的 `/api/act/*` 只是转发，落账、状态机、判据全在监制台那边。两处都能写就会有两本账。
- **数字读不到就说读不到**，不拿 0 冒充。任何一处失联都会明写原因（`ECONNREFUSED`／`超时`），
  因为一个显示"0 条待办"的值班屏和一个显示"读不到"的值班屏，是完全相反的两个意思。
- **没有的数就不画。** 在座栏那句说明是每一席协议里的原话；「这一席此刻在做什么」
  设计稿上画过，但按席的活动现在没有数据源——**画上去就是编一个状态**，所以没做。
- 坐席的工作目录是监制台（`D:\GitHub\AI-GameStudio\监制台`），所以它能直接读台账和工单目录。

## 验收清单

打开 `http://127.0.0.1:4280`，逐条对：

1. **主区只有一栏**，左右两边没有常驻列；页面本身不滚动，横向无溢出。
2. **顶条最左三格**：一个 6px 的点、`N验收 · N定夺 · …` ＋ 琥珀年龄章、`在跑 N · 最久 …`。
   徽标、额度、登录、钟**都不该在**。
3. **点「等你拍板」**：组头右边有「一次处置 N 单」；点它，说框里出现那一组的全部单号，条数对得上。
4. **点「监视」**：有「产线」段（在途/待派/候验收/已落袋 + 在跑列表），事件流只有一份。
5. **对话页右边有在座栏**，八席各带一句「管什么」；**切到任何别的页签它要收起来**。
6. **打一句话按 Enter**：先出现转圈和它在读什么，然后文字逐段出现，不是最后一次性蹦出来。
7. **追问一句**（比如"那它的上游是谁"），看它是否记得上一句——记得才说明会话续接是通的。
8. **把窗口最大化**（宽屏尤其要试）：正文要一直撑满窗宽，右侧不留黑带。
   0.11.0 及以前在屏宽 ≥2200 时会塌成左侧 400px 一条——拆栏时漏删了给旧的两根侧栏
   让位的那条媒体查询。0.12.0 修掉，判据 J10 在 1600/2200/2600/最大化 四档盯着。
9. **把监制台关掉**再刷新：顶条三格应说「读不到」，对话仍可用。
10. 登录有效时**不应**有琥珀横幅。想看它长什么样，控制台里跑
   `document.getElementById('凭幅').hidden=false`。

自检脚本（浏览器控制台里跑，量对比度／几何／溢出／强调色纪律）：

```js
await (await import('/_审屏.js')).审()
```

`对比全过: true` 且 `强调色越界: []` 即为过。

## 已知边界

- 服务只听 `127.0.0.1`，不对外。
- 关掉起它的窗口不影响它（`启动.bat` 以分离方式起）；要停就杀掉监听 4280 的 node 进程。
- 开机自启**已经做了**（计划任务 `\游戏开发者终端`，登录时起）。
  管它的口在 `server/lib/自启.js`，12 条判据顶着，装/卸都留回执。
  换装时**必须把任务指向的 exe 路径一起改**——不改的话下次登录起来的是旧版，
  而症状是「换了装但行为没变」，最难查的那一种。
