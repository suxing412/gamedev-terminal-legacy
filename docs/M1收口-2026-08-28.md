## 一、怎么用

```
node intel/run.js fetch     # 抓一轮（三源，先直连失败回退代理）
node intel/run.js digest    # 出当日日报（含真精编，约 2 分钟）
```

日报落 `data/digests/<日期>.md`，入选清单落同名 `.json`。
终端服务起来后**自动按班次跑**（07:10 / 12:10 / 22:10 抓取，08:20 出报），
读口 `GET /api/digest?日=YYYY-MM-DD`（不带参数＝当日；无当日报回最近七期列表，不留白屏）。

关掉自动调度：环境变量 `NO_INTEL=1`。

## 三、跑真源挖出的问题（都已修）

| # | 问题 | 性质 |
|---|---|---|
| 1 | **代理没走** | 我的错。施工令 P3 明写 `fetch(undici)+ProxyAgent`，我写成裸 fetch。**Node 内置 fetch 不认 HTTPS_PROXY 环境变量**（跟 curl 习惯相反），配置里 `走代理` 字段一直没人读 |
| 2 | **跨实例传 dispatcher** | 修 1 时打坏了能跑的：npm undici 的 ProxyAgent 传给 Node 全局 fetch（内置 undici），`UND_ERR_INVALID_ARG`，被 `fetch failed` 这层壳盖住。现在 fetch 与 dispatcher 同一实例，且**先直连再回退代理**（反过来会让可用性挂在 Clash 开没开上） |
| 3 | **UA 被当爬虫** | gamedeveloper 403。换常见浏览器 UA——读自己订阅的公开 feed，不绕付费墙 |
| 4 | **eXplorminate 死链** | 源侧：`/feed` 与 `/rss` `/?feed=rss2` 全 410 Gone（清单 08-25 还验通）。**标停用但留在配置里**——删掉就没人记得它为什么不在。S 档 SLG 垂直位暂缺 |
| 5 | **模型的自述印进日报** | 中文标注第一行是「只拿到标题和摘要，没有正文，所以…」。提示词已明写不要，模型仍加。**提示词是建议、代码才是闸**——加了元话语正则兜底，全被滤掉则按失败处置 |
| 6 | **日期两把尺** | `/api/digest` 用 UTC 日、出报用本地日，UTC+8 下每天 00:00–08:00 显示「查无日报」——**而日报恰恰是早上看的**。已统一，并立判据比对两处表达式逐字节一致 |
| 7 | **默认真通道烧了判据的额度** | 接通真精编后 m1a 端到端立刻开始打真实 API。加环境闸（`NO_INTEL`/`STUDIO_STUB` 下不走真通道）＋ 测试显式 `精编:false`。**默认走真通道是对的，但默认必须对测试无害** |

## 五、需要制作人的一件事

日报头条现在是**按新鲜度排出来的商业新闻，关键词得分 0**——`gamedeveloper` 全站条目源基础分相同，没有关键词命中时就只剩新鲜度在排序。

这说明 `config/scoring.json` 的权重表还没表达出你的口径。**这件我替不了你**：要你看着一份真日报说「这条该排前面 / 这条不该进」，我才调得动权重。判据 C3 已经守住「调权重则入选集合随之变化」，所以调完立刻能验。
