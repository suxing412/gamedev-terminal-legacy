## 三、九卷击杀的逐条堵法

### 3.1 丢数据类（最高优先，全部必须堵）

| # | 击杀 | 堵法 |
|---|---|---|
| K1 | **切页签就丢**：`视图.js:63/67/86` 三处 `innerHTML=`，textarea 连同未保存文本被删。**触发成本＝一次点击** | 编辑态下 `装片()` 前置检查脏态 → 拦截 + 确认；且草稿**每 800ms 落服务端**，不是内存 |
| K2 | **Ctrl+R 无确认**：`main.js` 绑死重载，而这是你肌肉记忆最强的键 | 编辑态下 `before-input-event` 拦 Ctrl+R 弹确认；且服务端草稿兜底 |
| K3 | **说话就冲掉编辑器**：`群聊.js:21` 发言成功后 `window.location.reload()` | 改成局部刷新，不整页 reload。**这个 bug 今天就在**，与编辑器无关也该修 |
| K4 | **换装 kill 进程**：换装是固定仪式不是异常，且恰好发生在"改完准备让我落地"那一刻 | 服务端草稿；重开自动恢复并提示 |
| K5 | **localStorage 草稿会在最需要时是空的**：4280 被占时 `start()` **顺延到 4281**，origin 一变 localStorage 就找不着了 | **不用 localStorage**，草稿一律落服务端 |
| K6 | **CRLF 全文变红**：HTML 规范要求 form 提交把 textarea 换行归一成 CRLF，一次保存 547 行全变改动行，"你标了哪几处"这条信息被淹掉 | **只走 `fetch` + JSON，绝不用 `<form>`**；且保存前按原文件的换行风格归一 |
| K7 | **BOM 静默改写首字符**：`readFileSync(...,'utf8')` 不剥 BOM，`\uFEFF#` 让一级标题降级成正文，textarea 里看不出异常 | 读时剥 BOM，写时不加；判据覆盖 |
| K8 | **内容穿过 shell**：`Set-Content`/`node -e` 会吃反引号、`${}`、`\n`、反斜杠，且多半不报错 | 写盘**全程走 `fs`**，一处不穿 |
| K9 | **`is_error` 类短路**（同族）：写失败但部分成功被记成正常 | 原子写：`tmp` + `rename`，失败即失败 |

### 3.2 并发写（可行性卷的主击杀）

**击杀原文的时刻表：**

> `21:04` 你打开文档，标了 3 个 `【删】`、写了 40 行，**一次都还没按存盘**。
> `21:26` 你在 §4.10 标了个 `【问】`，点「转交」。坐席读档、答问，**顺手把那行 `【问】` 替换成「（已答：…）」并 Edit 落盘**。
> 这不是越权——文档第 15 行那张记号表就是给它的契约（`【问】` ＝你不确定，要我先答）。
> `21:27` 你手上是 V1（25 分钟手工标注），盘上是 V2。三个按钮里「保留我的」需要三路合并，
> **而三路合并要 base 的字节，方案只存了哈希。**

四条堵法：

**① base 字节落盘，不只落哈希。**取档时服务端把 V0 复制一份到 `文稿/草/<id>.base.md`，与草稿同生命周期。没有 base，「保留我的」就是个空按钮。

**② 占用告示接进 `/api/say`，不只 `跑班次`。**转交发出的 prompt 自带前缀：

> `文稿/设计文档.md` 正在被制作人编辑，你可以读、**不要写**；要改就在回话里说改哪几行，由他落笔。

**③ 文档不搬家。**击杀指出：把文档搬进 `<终端根>/文档/` 会落进 `数据根 = D:\GitHub\AI-GameStudio`，而 `坐席选项()` 的 `additionalDirectories` 含它、`permissionMode:'acceptEdits'` 意味着**没有任何一步会问人**——**方案的前置条件亲手把写权造出来**。所以：**文档留在原地，根表显式配置**（§2 已如此）。

**④ 锁是服务端持有的，不是页面上的一个 class。**

### 3.3 锁的形状

```
取锁 POST /api/文稿/锁  { 路径 }
  → 服务端记 { 路径, 持有者, 起于, 末续, 末键 }
  → 返回 { 令牌, 文, 指纹, base已存 }

续租 每 15 秒（页面开着就续）
  租约超时 45 秒无续租        → 失效   （管崩溃/关页面/换装杀进程）
  闲置超时 30 分钟无按键      → 降级   （管人走了但页面开着）

降级 ≠ 解锁：转成「可抢占」，我请求即给，同时留一条记录给你
```

**闲置超时是必须的。**没有它，你晚上点了编辑就去睡，**02:00 的夜间巡检和整个白天我都动不了那个文件**——而系统看来"正在编辑"和"人走了"一模一样。

**解锁请求走哪儿：**左栏人闸队列一条（常驻可见、带等待时长、不打断）＋ 文件库里那个文件旁边一个标记。**不弹 Windows 通知**——你大概率正在改那份文档，弹通知打断你改文档是蠢的。

### 3.4 写口安全（终端无鉴权，这是第一个写口）

调研确认：**终端对外今天是纯只读的**——5 个 POST 口没有一条把请求体落盘。加写口是跨门槛的改动。

击杀构造的攻击（可复现）：

```js
// 任何网页里执行，你在 Unity 或浏览器里点开一个页面就够
fetch('http://127.0.0.1:4280/api/文稿/存', {
  method:'POST', mode:'no-cors',
  headers:{'Content-Type':'text/plain'},   // 简单请求，不触发预检
  body: JSON.stringify({路径:'...', 文:'...'})
})
// 响应读不到，但写已经发生
```

四道闸，全要：

1. **只收 `application/json`**——`text/plain` 一律 415。非简单请求会触发预检，同源策略才管得住
2. **校 `Origin`**——必须是本终端自己的 origin（含端口顺延后的）
3. **一次性写令牌**——页面加载时发，写请求必须带；令牌绑锁
4. **`校路径()` 三道**——形状 / realpath 落在某个根下（**父目录 realpath 后拼**，因为新建文件时 `realpathSync` 直接 throw）/ 是普通文件

> **`校档名()` 今天一条判据都没有**（`grep -rn "校档名" test/` 零命中），而它的注释自己写着"松一点就是任意文件读取"。加了写口，同一个洞变成**任意文件覆盖**。这一批必须补判据。

另：`express.json({limit:'1mb'})` 撞限时返回 **HTML 错误页**，前端 `r.json()` 抛 `SyntaxError: Unexpected token '<'`——你看到的是这句而不是"文档太大"。要拦成正常 JSON 错误。

### 3.5 判据跑道（成本卷的击杀）

**击杀指出两件事：**

**① `package.json` 根本没有 `test` 脚本。**13 个判据是逐个 `node test/x.test.js` 跑的。要加。

**② 用 `show:false` 的 Electron 窗做判据是陷阱。**hidden 窗的 `visibilityState` 恒为 `'hidden'`，Chromium **完全不派发 `requestAnimationFrame`**、把 `setTimeout` 节流到约 1Hz。而 CM6 的全部几何工作（视口测量、`coordsAtPos`、Decoration 定位）排在 rAF 上。后果是**同一条测道同时假绿和假红**：

- **常态假绿**：记号栏从来没渲染出来过，既验不了也不会因为坏掉而变红
- **随机假红**：草稿去抖 800ms vs 节流 1Hz 的赛跑，间歇性红

而"重跑到绿"这个习惯，正是本项目 2026-08-05 立 `deploy-ritual` 要禁的东西。

**堵法：判据分层，不碰 renderer 时序。**

| 层 | 验什么 | 怎么验 |
|---|---|---|
| 纯函数层 | 记号扫描、锚点计算、锁状态机、路径校验、换行/BOM 归一 | node 直跑，无 DOM |
| HTTP 层 | 取档/存档/锁/续租/超时/冲突三态/写口四道闸 | supertest 式打真服务 |
| **构建层** | **产物与源码一致** | 跑一次 build，比对产物；有差异即红 |
| DOM 层 | 只验静态结构（片段抠得出、`.视图` 包着、样式挂上） | 现有 `壳.test.js` 遍历页签表**白拿** |

**不写依赖 rAF 的判据。**记号栏的正确性用**纯函数层**验（给定文本 → 记号行号数组），DOM 那一跳不验——**明写这是判据盲区**，不假装覆盖了。

## 六、价值卷那条堵不掉，只能对冲

击杀说得对：**这块屏上需要你到场的格子，上线后 1–3 天全部凉透，基准率 100%。**席间存照走过三份方案、五轮异厂评审、52 条击杀（`docs/` 里躺着 `评审-席间存照-复评/三评/四评/五评` 四个文件），上线即死。

我堵不掉它。能做的只有两件：

**一 · 装埋点，让"有没有人用"变成可观测的。**约 10 行。现在六个页签一个埋点都没有，所以死掉的功能**不可观测、因而永久地挂在那儿**。装上之后两周有真实数据。

**二 · 把批一做成独立有价值的。**`md.js` 扩写服务的是班次报告和日报——**唯一活着的那格**。就算文稿台三天后没人点，这一批的价值不会跟着死。
