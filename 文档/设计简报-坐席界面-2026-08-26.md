# 设计简报 · 游戏开发者终端 · 坐席界面

日期：2026-08-26 · 状态：候制作人确认 · 流程：impeccable shape（v4.1.1）

## 1. 这是什么

一块 4K 全屏常驻的值班屏，替代现在的 CLI 窗口成为制作人与 AI 总监的唯一交互处。
三件事各安其位：**等你拍板的**（左）、**跟总监说话**（中）、**产线在跑什么**（右）。

核心指标只有一个：**「现在有什么等我」这个问题，不用问、不用点、不用滚动就有答案。**

## 2. 主行动

**说话**。不是点通过/不过——点击只用于把一条待办的上下文带进对话，决定始终通过对话下达。

## 3. 视觉方向

- **世界**：类别标准全力执行（制作人拍板的常设出口）。排版手艺照 Linear，信息密度与状态色系照 Datadog。
- **色彩策略**：Restrained（中性色 + 一个强调色 ≤10%）。理由：这是 Operate 模式的屏，整天在眼前，颜色必须是信号而非装饰——一旦有第二个抢眼的颜色，"谁在等我"就失去了唯一的视觉出口。
- **明暗（场景句）**：*一个人在夜里十一点半的书房，主显示器亮着这块屏，房间只有一盏侧灯，他刚从 Unity 切过来，眼睛已经用了六个小时。* → 暗色，且不是纯黑（避免高对比疲劳），近黑带极低冷灰。
- **强调色的唯一职责**：人闸告警。逾期越久越重（正常 → 提醒 → 逾期）。别处一律中性。
- **字体**：系统 UI 栈为主（中英混排的基线与字重最稳），等宽仅用于单号、时刻、数字列。不引入展示型字体——值班屏不需要个性，需要六小时后还能读。

## 4. 范围

三栏全布局 + 写口。总监能在界面内放行、审单、裁决、落账；每一次写都留痕到监制台的 journal。

## 5. 布局策略

- **中栏（对话）占主体**，宽度按 65–75ch 上限收敛，不铺满——长行是长时间阅读的敌人。
- **左栏（人闸）固定不滚动**：一行一条，逾期时长直接印在行上。这一栏永远不参与信息流，是它区别于聊天记录的根本。
- **右栏（脉搏）只报数与最近事件**：在途/待派/今日落袋，加一条时间轴。数字读不到时显示"读不到"，绝不显示占位数。
- **密度**：Datadog 级——三栏内容一屏装下，不靠滚动看全局。左右栏用 hairline 分隔而非卡片堆叠（卡片是偷懒答案，这里不需要）。

## 6. 关键状态

| 状态 | 用户需要看到 / 感觉到 |
|---|---|
| 默认 | 三栏都有内容，安静，无动效 |
| 人闸为空 | 左栏显示"当前没有等你的事"——这是好消息，要写得像好消息 |
| 人闸逾期 | 该行变重（强调色 + 时长），但不闪不跳 |
| 总监在思考 | 对话区有明确的"在跑"指示，且能看出跑了多久 |
| 产线读不到 | 右栏显示"读不到监制台（:4270）"，不是显示 0 |
| 写口失败 | 就地说明失败原因，不静默吞 |
| 首次打开 | 不做引导层。屏上就是真实数据，看一眼就懂 |

## 7. 交互模型

- 左栏一条 → 点击 → 该条的上下文进入对话输入区（"关于 TK-180："），焦点落到输入框
- 输入框：Enter 发送，Shift+Enter 换行
- 总监的写操作在对话里以行内确认出现（"已放行 TK-205，journal 已留痕"），不弹窗
- 键盘优先：`/` 聚焦输入、`Esc` 清空、数字键跳左栏第 N 条
- 动效纪律：只有"状态翻转"值得动（新事件到达、人闸变化），动一次即停，全部走 `prefers-reduced-motion` 降级

## 8. 内容需求

- 人闸队列：来自监制台 `/api/attn`（闸债，含逾期时长）
- 产线数字：`/api/board`（各态计数）、`/api/runner`（在跑会话）
- 事件流：journal 尾部
- 对话：spawn claude CLI（`-p --output-format stream-json` + session 续接），走订阅额度与既有 OAuth
- 空态文案要写成人话，不写"暂无数据"

## 9. 技术约束

- 原生 JS + CSS，无框架无构建链（与监制台一致，改起来快）
- Node + Express 后端，只读监制台 HTTP API，不碰它的文件
- 4K @150% 缩放：等效视口 2560×1440，物理像素密度高，可用更细字重
- 坐席进程与 CLI 并存，直到连续跑稳几天才让 CLI 退休（它挂了不能让制作人失联）

## 10. 反目标

- 不做 SaaS 仪表盘（卡片网格 + 彩色圆环 + 欢迎语）
- 不做整屏聊天框（那等于把 CLI 换了个壳，人闸照样淹）
- 不做黑客终端 cosplay（荧光绿 + 扫描线）
- 不做审批工作流（一行一条 + 通过/驳回两个按钮）

## 11. 未决
